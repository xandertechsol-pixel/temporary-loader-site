# Church Coming Soon Landing Page

A simple static landing page for a church website.

## Contents

- `index.html` — landing page markup
- `style.css` — page styling and animations

## Deploying to Vercel

1. Initialize a Git repository in this folder if not already done:

```bash
git init
```

2. Add and commit the files:

```bash
git add .
git commit -m "Initial landing page"
```

3. Create a GitHub repository and add it as a remote, for example:

```bash
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

4. Connect that repository to Vercel and deploy.

5. Add your custom domain in the Vercel dashboard.

## Vercel configuration

This project is static and can deploy directly to Vercel without a build step.
