# Church Coming Soon Landing Page

A simple static landing page for a church website.

## Contents

- `index.html` — landing page markup
- `style.css` — page styling and animations

## Deploying to Vercel

This project now uses Vite for the build system.

1. Install dependencies:

```bash
npm install
```

2. Initialize a Git repository in this folder if not already done:

```bash
git init
```

3. Add and commit the files:

```bash
git add .
git commit -m "Initial Vite landing page"
```

4. Create a GitHub repository and add it as a remote, for example:

```bash
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

5. Connect that repository to Vercel and deploy.

6. Add your custom domain in the Vercel dashboard.

### Local development

```bash
npm run dev
```

### Build locally

```bash
npm run build
```

## Vercel configuration

This project is static and can deploy directly to Vercel without a build step.
